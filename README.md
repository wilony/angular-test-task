# Image to Text

Веб-додаток, який розпізнає текст на зображенні через [API Ninjas Image to Text](https://api-ninjas.com/api/imagetotext).

- Завантаження JPEG/PNG до 2 МБ, попередній перегляд.
- Зображення стискається в браузері до <= 200 КБ (ліміт API).
- Розпізнаний текст виводиться на екран, є кнопка "Copy".

## Як це працює

1. Користувач обирає JPEG/PNG до 2 МБ, браузер перевіряє тип і розмір та показує попередній перегляд.
2. Перед відправкою зображення стискається в браузері до <= 200 КБ (ліміт API).
3. Фронтенд надсилає його на маленький бекенд (`POST /api/ocr`).
4. Бекенд додає API-ключ і пересилає зображення в API Ninjas.
5. Розпізнаний текст повертається на фронтенд і виводиться на екран.

## Структура

```
frontend/   Angular
server/     Express-бекенд, щоб заховати API-ключ
```

## Вимоги

- Node.js >= 24.15 (бо Angular CLI 22)
- Ключ API Ninjas з безкоштовного тарифу

## Запуск

Бекенд:

```bash
cd server
npm install
cp .env.example .env      # API_NINJAS_KEY обов'язково
npm start                 # http://localhost:3000
```

Фронтенд (в іншому терміналі):

```bash
cd frontend
npm install
npm start                 # http://localhost:4200
```


## Для чого маленький бекенд

Зберігати ключі на фронтенді не секурно, тому фронтенд смикає бекенд (`POST /api/ocr`). Маленький Express-сервер (`server/server.js`) додає заголовок `X-Api-Key` зі змінної оточення і пересилає запит до API Ninjas. Ключ живе в `server/.env` (у `.gitignore`) і ніколи не потрапляє у фронтенд. Зображення йде на сервер сирим тілом запиту (`Content-Type: image/jpeg` або `image/png`), без multipart, тому розмір тіла дорівнює розміру зображення. Завелике тіло сервер відхиляє з ерророю 413 ще до читання в пам'ять.

## Ліміти розміру

У проєкті є два ліміти, і обидва рахуються в двійкових одиницях (1 КБ = 1024 байти, 1 МБ = 1024 * 1024 байти):

| Ліміт | Значення | Навіщо |
|---|---|---|
| Файл, який обирає користувач | 2 МБ = 2 097 152 байти | Вимога завдання. Далі файл стискається |
| Зображення, яке йде в API | 200 КБ = 204 800 байт | Ліміт безкоштовного тарифу API Ninjas |


**Що змінювати, якщо ліміти колись зміняться:**

- Ліміт 2 МБ: `MAX_FILE_SIZE` у `frontend/src/app/core/utils/file-validator.ts`, текст помилки - підпис "up to 2MB" у `frontend/src/app/features/image-upload/image-upload.html` та тест `frontend/src/app/core/utils/file-validator.spec.ts`.
- Ліміт API (наприклад, інший тариф): `API_MAX_BYTES` у `frontend/src/app/core/utils/image-compressor.ts` (`API_MAX_SIZE_MB` для бібліотеки обчислюється з нього автоматично) і `MAX_IMAGE_BYTES` у `server/server.js`. Ці два значення мають завжди збігатися.

## Налаштування

- `API_NINJAS_KEY` - ключ API Ninjas (обов'язково).
- `CORS_ORIGIN` - адреса фронтенду, якій дозволено звертатися до бекенду (за замовчуванням `http://localhost:4200`).
- `PORT` - порт бекенду (за замовчуванням `3000`).
- Адреса бекенду для фронтенду задається в `frontend/src/environments/` (`environment.development.ts` для `ng serve`, `environment.ts` для прод збірки).

## Тести

```bash
cd frontend
npm test
```

Тести запускаються на Vitest у середовищі jsdom, браузер не потрібен.

Що покрито (7 тестів) - основні мінімальні вимоги:

- `file-validator.spec.ts` (3): валідація файлу перед завантаженням. JPEG і PNG приймаються, інші типи (GIF, PDF) відхиляються, рівно 2 МБ проходить, щось на 1 байт більше - ні.
- `ocr.service.spec.ts` (2): запит до бекенду без справжньої мережі. Зображення йде POST-запитом сирим тілом з правильним `Content-Type`, відповідь API склеюється в один рядок. Помилка HTTP (наприклад, 429) перетворюється на зрозуміле повідомлення.
- `text-result.spec.ts` (2): компонент результату. Кнопка "Copy" передає текст у буфер обміну, а якщо тексту немає, показується "No text detected".

## Проблема гонки запитів

 Якщо під час розпізнавання користувач обере інший файл, відповідь на попередній запит може перезаписати стан нового (текст чи помилку). Підписка на запит у `frontend/src/app/app.ts` не скасовується при виборі нового файлу. Це свідомо не виправлено: сценарій рідкісний, і я не знаю наскільки доцільно на зараз додавати ще й це.
